Corretor Inteligente PRO ULTRA
O Corretor Inteligente PRO ULTRA é uma aplicação web avançada de edição de texto e análise gramatical, desenvolvida com tecnologias web modernas (HTML5, CSS3 e JavaScript). A ferramenta integra-se com a API do LanguageTool para fornecer correções ortográficas e gramaticais precisas em tempo real, suportando múltiplos idiomas.

🚀 Principais Funcionalidades
Capa / Hero Banner Interativo: Apresentação visual sofisticada com acesso rápido às principais ações da ferramenta.

Correção Multilíngue: Suporte completo para Português (Brasil e Portugal), Inglês, Espanhol, Francês, Alemão e Italiano através da API do LanguageTool.

Estatísticas em Tempo Real: Contagem detalhada de caracteres, palavras, frases e erros detectados.

Visualização Avançada (Preview): Pré-visualização do texto com marcações visuais interativas destacando os erros e sugestões.

Correção Automática: Opção para aplicar correções individualmente por sugestão ou em lote com o botão "Corrigir tudo".

Modo Escuro / Claro (Dark/Light Mode): Alternância fluida de temas armazenada nas preferências locais.

Histórico e Recuperação: Sistema de salvamento de histórico de análises via localStorage e suporte completo a pilhas de Desfazer / Refazer (Undo/Redo via atalhos de teclado).

Ferramentas Utilitárias:

Leitura em voz alta do texto utilizando a síntese de voz nativa do navegador (SpeechSynthesis).

Importação e exportação de arquivos de texto (.txt, .md).

Cópia rápida para a área de transferência.

Personalização do tamanho da fonte do editor.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica da página.

CSS3: Estilização avançada com variáveis CSS, animações personalizadas e Flexbox/Grid responsivo.

JavaScript (ES6+): Lógica da aplicação, manipulação do DOM, requisições assíncronas à API e gerenciamento de estado local.

LanguageTool API: Motor externo de análise gramatical e ortográfica.

📂 Estrutura do Projeto
O código encontra-se consolidado em um arquivo único contendo:

Estilos globais e componentes visuais (<style>).

Estrutura de layout e interface do usuário (<body>).

Lógica de controle, consumo de API e persistência de dados (<script>).

🚀 Como Executar o Projeto
Como a aplicação roda inteiramente no lado do cliente (client-side), o processo de execução é extremamente simples:

Salve o código fornecido em um arquivo com a extensão .html (por exemplo, index.html).

Dê um duplo clique no arquivo salvo para abri-lo em qualquer navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).

Comece a digitar ou cole o seu texto no editor e clique em "Analisar texto".
